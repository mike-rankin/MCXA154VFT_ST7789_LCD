# MCXA154VFT_ST7789_LCD
NXP Custom Board using the MCXA154 processor and a 1.69 Inch Lcd
<img width="480" height="640" alt="Image" src="https://github.com/user-attachments/assets/1d3a386c-8e72-4d05-ba2a-0027deb8325a" />  
This board was created in Altium Designer because the NXP FRDM Dev boards have little on them to work with. So far the lcd and sensors work but not the external 20Mhz crystal. I plan on assembling another to test the CAN bus between both boards. The latest revision in the works uses a larger, slower 8Mhz crystal that is used on the FRDM dev board.
